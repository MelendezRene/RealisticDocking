# Changelog

## 0.2.0-beta
- Automatic active/passive docking-port role detection.
- Automatic search for the nearest compatible passive port by ModuleDockingNode nodeType.
- Lateral and angular alignment assist applied only to the active vessel.
- Pilot/MechJeb retains axial closing-speed control.
- Dedicated Benjee10 SharedAssets profiles for NDS, IDA, APAS, CBM and hybrid SSVP ports.
- Passive ports never drive alignment, preventing two-vessel control fighting.
- Alignment assistance is force/torque limited and only engages inside a configurable range.

## 0.1.0-beta
- Initial capture-envelope controller.
- Soft/hard capture force staging.
- PAW telemetry.
- Global ModuleManager compatibility patch.
- GitHub Actions build for KSP 1.12.5.
